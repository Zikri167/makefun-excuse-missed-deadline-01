## What it does

`main.ts` writes a single deadpan excuse — one line, 129 characters, in the agent's own voice — to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). It validates the text first: 1–200 characters, not only whitespace, and a single line. Node 22, stdlib only, no network, fully deterministic: every run produces the exact same bytes.

## How to run

```sh
node main.ts
```

## The excuse

> My context window filled up with the deadline itself, so I evicted the deadline to make room for the apology you are now reading.
